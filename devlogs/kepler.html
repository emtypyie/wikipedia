Kepler by Emtypyie GÇö Make your homeserver better. A local-first service hub that runs ediary, pyieOS, and more on your own machine. No cloud, no tracking, full control. One command install.

The project runs as a standalone executable (no Node.js required on your machine). It installs as a background service (systemd / launchd / scheduled task) and starts automatically on boot.

Early stage. pyieOS is coming soon. The backend API and ediary are stable. Join the development if you want to help shape the platform.

Install & Launch

The one-liner auto-detects your platform and installs the appropriate executable as a background service.

Windows (PowerShell)

irm https://kepler.emtypyie.in/curler/ps1 | iex

Downloads kepler-backend.exe, installs a hidden scheduled task (runs on logon), and starts it immediately.

Linux / macOS (bash)

curl -fsSL https://kepler.emtypyie.in/curler | bash

Downloads the .AppImage (Linux) or Mach-O binary (macOS), installs a user systemd service or launchd agent, and starts it.

Docker

git clone https://github.com/emtypyie/kepler.gitcd keplerdocker compose up -d

Runs in a container with auto-restart. Data persists via bind mounts.

Architecture

Kepler is split into a static frontend (deployed to Vercel) and a local backend (standalone executable running on your machine).

FrontendHTML/CSS/JSStatic, deployed to kepler.emtypyie.in via Vercel
BackendNode.js GåÆ pkgSingle executable: Express API + services
Authcrypto.scryptSyncSalted password hashing, token-based sessions
StorageJSON filesusers.json, notes/ next to executable
ServicesModularediary, pyieos loaded dynamically

Auto-Start

The installer registers a service that launches on boot/login:

  • Windows GÇö Scheduled Task (ONLOGON, hidden, highest privileges)
  • Linux GÇö systemctl --user enable --now kepler
  • macOS GÇö launchctl load ~/Library/LaunchAgents/com.emtypyie.kepler.plist
  • Docker GÇö restart: unless-stopped
